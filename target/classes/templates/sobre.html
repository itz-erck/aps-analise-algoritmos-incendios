Sobre o projeto

Sistema de análise de desempenho de algoritmos de ordenação.

ⓘ

Objetivo e tecnologias

Este projeto tem como objetivo analisar e comparar o desempenho de cinco algoritmos de ordenação utilizando dados de focos de incêndio de 2023 e 2024. O sistema permite organizar os registros por data, bioma e município, avaliando métricas como tempo de execução, comparações, trocas e movimentações, além da complexidade teórica Big O. Também realiza previsões mensais para os seis meses seguintes com base no histórico de ocorrências, permitindo observar possíveis tendências, sem garantir os valores estimados. Para o desenvolvimento, foram utilizadas Java, Spring Boot e Thymeleaf na estrutura da aplicação, HTML, CSS e JavaScript na interface, e Maven para gerenciar as dependências do projeto.
